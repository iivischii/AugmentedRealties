# Augmented Realties

An academic team project that explores where **real estate, augmented reality and digital technology** meet. The idea started from growing up around a realtor and knowing how tiring "house tripping" can be: what if you could walk through a property before you ever visit it?

**Live site:** https://augmentedrealties.vercel.app

![Augmented Realties home page](docs/home.png)
![Augmented Realties on mobile](docs/mobile.png)

## About the project

Augmented Realties brings several ideas into one concept: browsing properties, using AR to preview them, and using AI to support the experience. It was built by team **Napoles & Co.** as a school project, and it's an idea we'd love to keep exploring.
